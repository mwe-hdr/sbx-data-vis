### Collapse into clean categories:

```python
def simplify_disposition(x):
    x = str(x).lower()
    if "admit" in x:
        return "Admit"
    elif "discharge" in x:
        return "Discharge"
    elif "lwbs" in x:
        return "LWBS"
    elif "psych" in x:
        return "Psych"
    elif "ob" in x:
        return "OB"
    else:
        return "Other"
```

# 🔷 Step 3: Create Flow Transitions (Python)

A Sankey requires:

* `source`
* `target`
* `value`

### Build transitions

```python
import pandas as pd

df_flow = df.copy()

# Flags for stage completion
df_flow["has_triage"] = df_flow["triage_start_dtm"].notna()
df_flow["has_ed"]     = df_flow["ed_start_dtm"].notna()

# Simplify disposition
df_flow["disposition_simple"] = df_flow["disch_disp_desc"].apply(simplify_disposition)

links = []

# ----------------------------------------
# 1. Arrival → Triage / No Triage
# ----------------------------------------
links.append({
    "source": "Arrival",
    "target": "Triage",
    "value": df_flow["has_triage"].sum()
})

links.append({
    "source": "Arrival",
    "target": "No Triage",
    "value": (~df_flow["has_triage"]).sum()
})

# ----------------------------------------
# 2. Triage → ED or Exit
# ----------------------------------------
triage_df = df_flow[df_flow["has_triage"]]

links.append({
    "source": "Triage",
    "target": "ED Treatment",
    "value": triage_df["has_ed"].sum()
})

links.append({
    "source": "Triage",
    "target": "Left Before ED",
    "value": (~triage_df["has_ed"]).sum()
})

# ----------------------------------------
# 3. ED → Disposition
# ----------------------------------------
ed_df = df_flow[df_flow["has_ed"]]

disp_counts = ed_df["disposition_simple"].value_counts()

for disp, count in disp_counts.items():
    links.append({
        "source": "ED Treatment",
        "target": disp,
        "value": count
    })

links_df = pd.DataFrame(links)
```

***

# 🔷 Step 4: Build Sankey (Python Visualization)

### Using Plotly

```python
import plotly.graph_objects as go

labels = list(set(links_df["source"]).union(set(links_df["target"])))
label_map = {label: i for i, label in enumerate(labels)}

fig = go.Figure(data=[go.Sankey(
    node = dict(
        pad=15,
        thickness=20,
        label=labels
    ),
    link = dict(
        source=links_df["source"].map(label_map),
        target=links_df["target"].map(label_map),
        value=links_df["value"]
    )
)])

fig.show()
```

# 🔷 Step 6: Funnel Chart (Much Easier + Often Better)

Instead of Sankey, create:

### Funnel:

| Stage   | Count       |
| ------- | ----------- |
| Arrival | total rows  |
| Triage  | has\_triage |
| ED      | has\_ed     |
| Admit   | admitted    |

### Python:

```python
funnel = pd.DataFrame({
    "stage": ["Arrival", "Triage", "ED Treatment", "Admit"],
    "count": [
        len(df),
        df["has_triage"].sum(),
        df["has_ed"].sum(),
        (df["disposition_simple"] == "Admit").sum()
    ]
})
```
