# 🚀 2. High-Impact Analytics You Should Add

## A. Patient Flow + Throughput Modeling (MOST IMPORTANT)

### 🔹 New metrics to engineer in Python

From timestamps:

```text
Door-to-triage = triage_start - visit_dtm
Triage-to-provider = ed_start - triage_stop
Provider-to-disposition = ed_end - ed_start
Boarding time = boarding_end - boarding_start
Total LOS = end_dtm - start_dtm
```

### 🔹 Visualizations (Tableau)

* **Sankey diagram or flow funnel**  
  Visit → Triage → ED → Admission / Discharge
* **Boxplots by acuity**
  * LOS distribution by acuity
* **Waterfall / decomposition chart**
  * Where time is spent in the ED journey

👉 Why this matters:

* Identifies *operational bottlenecks* (triage vs provider vs boarding)
* More actionable than census alone
