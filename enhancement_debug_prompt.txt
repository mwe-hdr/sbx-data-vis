### FRAMEWORK OVERVIEW

The reporting framework operates in three stages.

Stage 1
PROCESSING_MODE = parameters_only
Produces parameterized report definitions.

Typical flow:
vis_driver.csv
+
visual parameter csv files
+
cohort definitions
→ processing_driver.csv

Stage 2
PROCESSING_MODE = full_reports
Produces final reports.

Typical flow:
processing_driver.csv
→ main.py
→ row_to_params()
run(
    df,
    params,
    start_date,
    end_date,
    output_dir,
    enabled_visuals
)
→ PNG outputs
→ parameter outputs
→ legend outputs
→ RDB outputs

Stage 3
PROCESSING_MODE = powerpoint
Produces powerpoint output from Stage 2 outputs.

Typical flow:
→ main.py
→ build_powerpoint(
	run_id,
	template_file,
	output_file
)
→ PPTX output
